# Question Sprout Study Hub

Step 1: Question Bank Website — UI Only



Next.js + TypeScript + Tailwind CSS ব্যবহার করে একটি modern, responsive Question Bank Website-এর শুধু Frontend UI তৈরি করো।



Requirements:



- Clean, professional ও student-friendly design।

- Mobile, tablet ও desktop responsive layout।

- Navbar: Logo, Home, Subjects, Plans, Login ও Register।

- Homepage: Hero section, Search Bar, Subject Cards, Popular Questions, Subscription Plans এবং Footer।

- Subject হিসেবে Physics, Chemistry, Biology, Mathematics ও ICT দেখাও।

- Subscription Plan Card-এ Price, Duration, Features ও Subscribe Button রাখো।

- Login ও Register-এর UI তৈরি করো।

- আপাতত Admin Dashboard এবং User Dashboard-এর basic static UI layout রাখো।

- Mock data ব্যবহার করো; কোনো real backend প্রয়োজন নেই।

- Button ও Navigation-এর প্রয়োজনীয় basic frontend interaction রাখো।

- সুন্দর typography, consistent spacing, reusable components ও accessible design অনুসরণ করো।



Strict Limitations:



- Supabase, Database, API, Authentication logic, Payment Gateway বা Subscription logic তৈরি করবে না।

- কোনো অতিরিক্ত Feature যোগ করবে না।

- শুধু Step 1-এর UI তৈরি করে থামবে।

- Existing project থাকলে আগে তার structure দেখে বর্তমান setup অনুযায়ী কাজ করবে।

- কাজ শেষে তৈরি হওয়া UI pages ও components-এর সংক্ষিপ্ত তালিকা দেবে।
